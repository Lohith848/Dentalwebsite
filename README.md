## Overview

**Smile Care Dental** is a clean and premium single-page dental clinic website built using **HTML5** and **CSS3**.

The design focuses on simplicity, trust, elegance, and patient-friendly navigation while maintaining a modern luxury appearance suitable for professional dental clinics.
